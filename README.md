Into golf is een bedrijf dat software maakt dat specifiek alles met golf te maken heeft.

de opdracht is een proof of concept maken voor een progressie pagina voor golfer in hun app. 
Als je als golfer ingelogged bent en een je handicap score wilt bij houden dan ga je naar die pagina.

wat ik heb gemaakt is de main score die je als golfer hebt en een lijst met de laaste 5 rondes die er gespeeld zijn. Ook is er een formulier waar je een ronde kan toevoegen.
